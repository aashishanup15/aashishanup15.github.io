# keep it under CONTROL_

Asis Anupam Mohanty's electronics and electrical engineering portfolio. Industrial automation, PLCs, SCADA and plant instrumentation, with a scroll-driven narrative and a playable tank-control game.

## Run locally

Open index.html directly, or run `node serve.mjs` and visit http://127.0.0.1:4188. No build or dependency installation is required. Google Fonts have system-font fallbacks.

## Checks

Run `node check.mjs` for content, navigation, scroll timeline and game logic checks.

## Deployment

GitHub Pages serves these files from the main branch root. Resume download: assets/resume.pdf.
